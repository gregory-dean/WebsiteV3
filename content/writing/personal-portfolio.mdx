## Why rebuild it

I originally shipped [WebsiteV1](https://github.com/gregory-dean/WebsiteV1) as hand-built HTML, CSS, and JavaScript so I would learn the stack from scratch. [WebsiteV2](https://github.com/gregory-dean/WebsiteV2) moved that into Next.js, GSAP, and Three.js.

This is [WebsiteV3](https://github.com/gregory-dean/WebsiteV3). Same job: one place for experience, labs, and writing. The particle hero is still here. The writing lives in MDX. The site exports statically and ships through GitHub Pages.

## What's here

- Experience from IT support through Evolve Security Academy to security systems work
- The 10 inch homelab, documented as it actually runs
- Tools I built, with the notes attached

Keeping the repo public means the site itself is a code sample.
