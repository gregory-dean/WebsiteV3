## Why rebuild it

I originally shipped a hand-built HTML, CSS, and JavaScript site to learn the stack from the ground up. This version keeps that spirit, one place for experience, labs, and writing, while adding the interactive particle hero and a clearer home for project documentation.

## What's here

- Experience from IT support through Evolve Security Academy to security systems work
- Homelab and tooling projects documented as public labs
- A writing surface for detection notes and assessment-related tooling

The site is statically exported with Next.js and served through GitHub Pages, with MDX powering the writing section and Three.js driving the particle scene. Keeping the whole thing in a public repo means the site itself doubles as a code sample.
